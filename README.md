# 🆘 Emergency Contact - 긴급 연락처 앱

해외에서 긴급 상황 시 **3초 안에** 필요한 연락처를 찾을 수 있는 초간단 앱입니다.

## ✨ 주요 기능

- 🚨 **원터치 긴급 호출**: 앱 실행 → 국가 선택 → 전화 버튼 (3초)
- 🌍 **50개국 지원**: 주요 여행 국가의 긴급 연락처 제공
- 📱 **오프라인 모드**: 인터넷 없이도 작동 (PWA)
- 📍 **위치 기반 자동 감지**: 현재 위치 기반 국가 자동 선택
- 📋 **상황별 가이드**: 여권 분실, 병원 필요, 범죄 피해 등

## 🚀 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.

### 빌드

```bash
npm run build
npm start
```

## 🎯 핵심 기능

### 1. 원터치 긴급 호출
- 메인 화면에서 큰 빨간 버튼 클릭
- 위치 기반 자동 국가 감지
- 3초 안에 긴급 연락처 접근

### 2. 오프라인 모드
- Service Worker를 통한 오프라인 지원
- 모든 데이터 앱 내 저장
- 인터넷 없이도 작동

### 3. 상황별 가이드
- 여권 분실: 대사관 연락처 및 절차
- 병원 필요: 응급실 + 번역 카드
- 범죄 피해: 경찰 + 대사관 동시 연락

## 🛠 기술 스택

- **Next.js 15**: React 프레임워크
- **React 19**: UI 라이브러리
- **Tailwind CSS**: 스타일링
- **PWA**: 오프라인 지원
- **Service Worker**: 캐싱 및 오프라인 기능

## 📱 PWA 설치
